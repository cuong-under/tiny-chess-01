A compact chess engine in 4 KB of Python: 0x88 board, alpha-beta search with quiescence, transposition table and killer moves, formulaic piece-square tables, and a fixed node budget per move (no clock, so replayed trials play the same moves). It plays the house gauntlet through the env at MAKEFUN_ENV_URL.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
